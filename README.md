## Структура репозитория и реализованные задания

### 1. Операции над множествами (процедурный подход)
**Файл:** `set_operations.c`
Реализация операции \( E = (A \cup B) \setminus (C \cup D) \) с использованием четырех различных структур данных (массивы, списки, битовые массивы, машинные слова) и замер производительности.

### 2. Операции над множествами (ООП и перегрузка операторов)
**Папка:** `set_operations_oop/`
Объектно-ориентированная реализация той же задачи. Создан класс `Set` с перегрузкой операторов `|`, `&`, `~`. Реализация разбита на заголовочные файлы для разных структур данных (`Set_array.h`, `Set_list.h`, `Set_bitarray.h`, `Set_machine.h`).

### 3. Работа с деревьями
**Папка:** `tree/`
Реализация структуры данных "Дерево" на C++.
* Файлы: `Tree.cpp`, `Tree.h`, `main.cpp` (демонстрация работы).

### 4. Работа с графами
**Папка:** `graph/`
Реализация алгоритмов на графах.
* Файлы: `graph.cpp`, `graph.h`, `main.cpp` (демонстрация работы).

### 5. Геометрические фигуры (базовая реализация)
**Папка:** `shape/`
Реализация классов геометрических фигур с использованием ООП.
* Файлы: `shape.cpp`, `shape.h`, `screen.h`.

### 6. Геометрические фигуры с обработкой исключений
**Папка:** `shape_exceptions/`
Расширенная реализация геометрических фигур с добавлением механизма исключений (Exceptions).
* Файлы: `shape.cpp`, `shape.h`, `screen.cpp`, `screen.h`, `exceptions.h`.

### 7. Комбинированные структуры данных
**Файл:** `comb_data_structures.cpp`
Реализация комбинированных структур данных.

### 8. Анализ сложности алгоритмов
**Файл:** `time_complexity_of_algorithm.cpp`
Исследование временной сложности алгоритмов.
